# Jiggy-Stealth v1.2.0

Ready-to-flash firmware for the **Adafruit Feather RP2040 USB Host (product 5723)**, with a complete source/build package.

## Downloads

- **Jiggy-Stealth.uf2** — install directly; no compiler or development tools needed.
- **Jiggy-Stealth-v1.2.0-source.zip** — complete tagged project, including firmware sources, build/setup scripts, pinned dependency manifest, prebuilt UF2 files, documentation, and licenses.
- **FLASHING.txt** — short installation and controls guide.
- **SHA256SUMS.txt** — SHA-256 checksums for the three assets above.

## Flash and use

1. Connect USB-C to your computer. Hold **Boot**, press/release **Reset**, and release Boot when **RPI-RP2** appears.
2. Copy **Jiggy-Stealth.uf2** to that drive. The board restarts automatically.
3. Plug your paired mouse receiver or supported mouse into USB-A.

**Movement is the default. Jiggle starts OFF.** Short-press Boot to enable or disable it; green means Movement enabled. After 30–60 seconds without real mouse activity, it adds a small excursion and return. Hold Boot for two seconds to choose Movement or Shift; a short press is required to enable the selected mode.

Wireless receivers must already be paired directly on the computer. Tested with a Logitech M305 and its 046D:C52B receiver. Other mice and receivers have not been hardware-qualified.

## Included behavior and verification

- Mouse movement, buttons, vertical wheel, and horizontal pan are forwarded with real input taking priority.
- USB vendor/product IDs and identity strings come from the attached receiver/mouse. The bridge uses its own composite HID/diagnostic layout; it does not relay vendor pairing or configuration protocols.
- Optional Movement and brief Shift pulses are controlled by the physical button. Timing and movement distance are configurable in source.
- **26,471 native checks passed.** The v1.2.0 build was flashed and its Movement/off startup state was verified. Earlier hardware validation confirmed a two-pixel excursion and return on the reference Windows setup; wider hardware and physical Shift testing remain documented coverage limits.

Build instructions and coverage are in the [versioned user guide](https://github.com/neusse/Jiggy-Stealth/blob/v1.2.0/docs/USER_GUIDE.md) and [verification record](https://github.com/neusse/Jiggy-Stealth/blob/v1.2.0/docs/VERIFICATION.md). Source builds require the documented prerequisites; setup downloads the pinned core and libraries.
