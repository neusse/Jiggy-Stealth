# Jiggy-Stealth v1.4.0

**Movement mode now advertises only a mouse.** The keyboard HID collection is added only when you explicitly select Shift mode, and removed when you return to Movement. This applies to both Production and Diagnostics, whether jiggle is enabled or off.

Every restart selects **Movement, jiggle OFF, no keyboard**. Mouse forwarding and donor USB identity remain available in both modes. The target board is the **Adafruit Feather RP2040 USB Host (product 5723)**.

## Downloads

- **Jiggy-Stealth.uf2** — Production: mouse-only HID at startup; no USB serial/COM port in either mode.
- **Jiggy-Stealth-Diagnostics.uf2** — the same full bridge and HID mode selection, plus USB serial troubleshooting.
- **Jiggy-Stealth-v1.4.0-source.zip** — complete tagged source/build project, both bridge UF2s, pinned dependency manifest, documentation, and licenses.
- **FLASHING.txt** — quick installation, controls, and recovery instructions.
- **SHA256SUMS.txt** — checksums for the four downloads above.

## Mode controls

Short-press Boot to enable or disable the selected activity. Hold Boot for two seconds during normal operation to select Movement/Shift. A mode change briefly disconnects and reconnects USB to update the HID descriptor, pausing mouse forwarding, and **always leaves jiggle off**. Short-press separately to enable it.

Selecting Shift advertises the keyboard even before activity is enabled. Selecting Movement removes it entirely; keyboard report requests/sends are also blocked in Movement. A held Shift gets a bounded key-release opportunity before the old USB device disconnects. The existing mouse idle delay and randomized 30–60 second intervals are unchanged. Keyboard passthrough is not implemented.

A receiver identity update arriving during a USB reconnect replaces the queued identity, including a rapid removal/reinsertion of the same receiver.

## Installation and recovery

Connect USB-C with a data cable. Hold **Boot**, press/release **Reset**, and keep Boot held until **RPI-RP2** appears. Copy **one** chosen UF2 to that drive; the board restarts automatically. Plug the already-paired mouse receiver into USB-A.

UF2 installation, switching builds, and recovery do not need serial. Production updates use Boot/Reset; automatic COM uploads and status/capture commands require Diagnostics. A mode change also reconnects diagnostic serial, so reopen captures and recheck the port.

## Verification

Both profiles compile for the pinned RP2040 target and pass **26,661 native checks each**. Added checks inspect actual HID application collections and report IDs, block keyboard reports in Movement, exercise repeated layout changes with matching report lengths, and retain a held Shift release across mode selection.

Hardware checks confirmed mouse-only fallback startup, keyboard addition on selecting Shift, and keyboard removal on returning to Movement in Diagnostics. The M305 delivered **853 physical events and 853 forwarded packets** with no decode errors or overflows after returning to Movement. Production also passed the physical Movement-to-Shift-to-Movement cycle: mouse only, then mouse plus keyboard, then mouse only again, with no COM port in any mode. Details and remaining coverage limits are in the [versioned verification record](https://github.com/neusse/Jiggy-Stealth/blob/v1.4.0/docs/VERIFICATION.md).

See the [versioned user guide](https://github.com/neusse/Jiggy-Stealth/blob/v1.4.0/docs/USER_GUIDE.md) for building, configuration, diagnostics, and recovery.
