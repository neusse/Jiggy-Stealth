# Jiggy-Stealth v1.3.0

Two ready-to-flash builds for the **Adafruit Feather RP2040 USB Host (product 5723)**. Both retain mouse forwarding, mouse/keyboard HID, donor USB identity, and optional Movement/Shift activity. **Movement is the default; jiggle starts OFF after every restart.**

## Choose a build

| File | Purpose |
| --- | --- |
| **Jiggy-Stealth.uf2** | Production: mouse + keyboard HID, no USB serial/COM port |
| **Jiggy-Stealth-Diagnostics.uf2** | The same full bridge with USB serial status, descriptor inspection, and raw-packet capture |
| **Jiggy-Stealth-v1.3.0-source.zip** | Complete tagged source/build project, both bridge UF2s, pinned dependency manifest, docs, and licenses |
| **FLASHING.txt** | Quick installation, profile selection, controls, and recovery instructions |
| **SHA256SUMS.txt** | SHA-256 checksums for all four downloads above |

Production suppresses the Arduino core's automatic serial startup before the USB controller initializes. It also omits serial when discovering a receiver, exposing fallback HID without a receiver, or reconnecting. Diagnostics keeps HID first and adds CDC afterward. The diagnostic build is a working bridge, distinct from the older receiver-only developer probe.

## Install, update, or switch builds

1. Connect USB-C with a data cable. Hold **Boot**, press/release **Reset**, and keep Boot held until **RPI-RP2** appears.
2. Copy **one** chosen UF2 onto that drive. The board restarts automatically.
3. Plug the paired mouse receiver or supported mouse into USB-A.

**Serial is not required for UF2 updates.** Boot/Reset enters the RP2040 ROM bootloader independently of either application image. Production has no COM port for automatic serial uploads; use these same manual steps for later updates or to install Diagnostics.

Short-press Boot to enable/disable jiggle. Hold Boot for two seconds during normal operation to select Movement/Shift; the selected mode remains off until a short press. Green means Movement enabled, amber Shift enabled, and dim blue off.

## Verification and compatibility

Both profiles compile for the pinned RP2040 target and pass **26,500 native checks each**, including USB startup deferral, first-connect interface selection, device classes, identity, reconnect/fallback handling, and the existing mouse/scheduler/button suite. The native USB boundary fake tests the actual startup and identity modules; it does not replace hardware USB enumeration checks.

Both images were flashed to the reference Feather. Windows enumerated Production with healthy mouse/keyboard HID devices and no COM port. Diagnostics reported version 1.3.0, Movement selected, jiggle off, complete receiver identity, and zero decoding/queue/host errors. A fresh physical input and manual recovery session for this version is still pending.

The qualified mouse/receiver remains a Logitech M305 with a 046D:C52B receiver. The bridge uses its own HID report layout and does not relay Logitech pairing or configuration protocols. Broader mice, physical Shift, and suspend/resume still have the coverage limits in the [verification record](https://github.com/neusse/Jiggy-Stealth/blob/v1.3.0/docs/VERIFICATION.md).

See the [versioned user guide](https://github.com/neusse/Jiggy-Stealth/blob/v1.3.0/docs/USER_GUIDE.md) for source builds, diagnostics, and recovery. The complete source ZIP includes build scripts and pinned dependencies' source locations; setup downloads the toolchain and libraries.
